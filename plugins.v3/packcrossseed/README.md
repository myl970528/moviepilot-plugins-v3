# 拆包辅种 PackCrossSeed

MoviePilot 插件：把下载器里已完成的整包种子，按「电影整文件 / 剧集单集」拆开，
逐个到 MoviePilot 已配置的站点搜索独立种子，做 piece 级内容校验，确认内容一致后
用硬链接生成不占空间的独立副本，交给目标下载器重新校验并辅种。原包与原任务全程不动。

## 它解决什么问题

PT 站常见的场景：一个整季 / 合集包同时在多个站做了辅种，但站内的独立单集种子
（每一集一个种子）没有对应的做种副本。本插件把整包拆成单集，去匹配这些独立种子，
校验内容一致后为每个单集生成一份硬链接副本并单独做种，从而提升多站的做种覆盖与分享率。

## 工作流程

1. **发现** 从已配置的下载器读取已完成任务，解析其 `.torrent`，列出包内视频文件，
   按单集拆成待匹配单元（电影则取整文件）。
2. **匹配** 用单集文件名调用 MoviePilot 的站内搜索，按体积 + 名称相似度筛选候选，
   只在 MoviePilot 已配置的站点里找。
3. **校验** 下载候选种子，解析出 pieces 与 piece length，对本地单集文件逐片做
   SHA1 对比（支持跨文件 piece 字节流）。内容不一致的候选直接淘汰。
4. **物化** 校验通过后，按候选种子的文件布局，在输出目录优先硬链接、其次软链接、
   最后复制，生成独立副本。源文件只读。
5. **加种** 把候选种子交给目标下载器，指定新目录，添加后由下载器 recheck 做种。

## 安全设计

- **默认试跑**：只做发现、匹配、校验，不写盘、不加种。确认结果后再关闭试跑模式。
- **源文件只读**：不对原包做任何写入、改名或移动。
- **可回滚**：每次运行的写操作记录在 journal 里，可通过 `/rollback` 接口清理新副本。
- **限流友好**：站内搜索复用 MoviePilot 搜索链路，种子下载走宿主 HTTP SDK，
  遵守站点配置间隔；每个单集只校验有限数量的候选，控制请求量。
- **判重**：加种前按 infohash 比对目标下载器现有任务，已存在的跳过。

## 安装

将本目录放到 MoviePilot 插件目录（小写 `packcrossseed`），重启或重载插件即可。

不需要额外 Python 依赖：种子解析使用 MoviePilot 运行环境自带的 `torrentool`，
网络请求与站点信息走宿主稳定 SDK（`app.sdk.network`），下载器列表走
`app.sdk.services`。

## 配置

配置页所有字段默认值均为空 / 中性，需使用者自行填写：

- **来源下载器**：从哪些下载器的已完成任务里拆包，运行时从 MoviePilot 拉取。
- **加种下载器**：校验通过的种子加到哪一台。
- **辅种副本输出目录**：独立副本写在哪里；需与源目录同一文件系统才能硬链接。
- **站点范围**：参与匹配的站点，运行时从 MoviePilot 拉取；留空表示全部启用站点。
- **只处理这些任务**：按任务名过滤，试点时用它锁定一个包；留空表示处理全部任务。
- **校验片数**：试跑时只校验前几片，正式运行填 0 做全量校验。
- **副本生成方式**：自动（硬链优先、逐级降级）/ 仅硬链 / 仅软链 / 仅复制。

## 使用顺序

1. 保持「试跑模式」开启，点「扫描生成计划」查看会拆出哪些单元。
2. 点「执行一轮」查看匹配与校验结果，此时不写盘。
3. 详情页确认校验通过后，关闭试跑模式，填写输出目录与目标下载器，再执行一次。

## 接口

插件注册在 `/api/v1/plugin/PackCrossSeed` 下：

- `POST /scan` 扫描生成计划（只读）
- `POST /run` 执行一轮
- `GET /status` 查询状态与进度
- `POST /rollback` 回滚上一轮生成的新副本

## 隐私

本插件源码不包含任何站点域名、IP、账号、Cookie、令牌、设备标识或本地目录。
下载器与站点列表在打开配置页时从 MoviePilot 运行时读取；站点 Cookie 仅在内存中
交给 MoviePilot 的种子下载服务使用，不写入日志、不落盘。所有涉及个人环境的字段
均需使用者自行填写或从 MoviePilot 拉取。
